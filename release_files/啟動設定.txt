# ===== ① 共用設定（兩種模式都會用到）=====

# 【模式】請填：換房　或　掛房　或　通知
#    換房 = 一桌一桌巡，找名單上的人跟著下注
#    掛房 = 固定待在「目前這一桌」跟注，不換桌
#    通知 = 只盯場、不下注：巡各房，抓到追蹤對象下『邊注』（莊/閒不算）就發 Telegram
#           通知你「誰在哪一房開始下注了」，並『原地暫停』等你接手手動下注；
#           下注完成後在該台電腦按 Ctrl+Alt+R 恢復巡邏（不用重開程式）。
#           適合對方故意超晚下注（自動跟來不及）時改由人工判斷、手動跟。
#    （想先做開機自我檢查，這行改填：檢查）
#    （找不到星城視窗時，這行改填：視窗診斷）
#    （校正餘額/帳號讀取位置，這行改填：餘額測試）
模式=換房

# 【下注】請填：開　或　關
#    開 = 實戰，會真的下注
#    關 = 測試，只會辨識、開關統計表，但不下注
下注=開

# 【帳號】這台掛機的玩家帳號名稱（餘額上傳到試算表時用）。
#    直接打字輸入，不再用 OCR 辨識名字（OCR 容易讀錯）。例：帳號=我的帳號名
帳號=

# 【跟注比例】跟注金額 = 對方金額 × 隨機比例，再無條件進位到整數注（最低 1000）。
#    避免每把都跟對方一模一樣太明顯。
#    填範圍每把隨機（建議）：例 跟注比例=0.8-0.99
#    填單一值=固定比例（例 跟注比例=0.9）；填『關』=跟對方原額；留空=用預設 0.8~0.99。
跟注比例=0.8-0.99

# 【單注上限】風控：對象在「單一下注區」下超過這個金額就「不跟」（防爆量單／最後一秒收回）。
#    例：單注上限=20萬。填『不限』或 0 = 不限制。留空 = 用預設 20 萬。
單注上限=20萬

# 【單局總下注警告】提醒用（不影響跟注）：對象「同一局」多注加總（含莊/閒，
#    例如 和19萬＋幸運六19萬＝38萬）超過這個金額，就發 Telegram 警告通知。
#    與「單注上限」不同：單注上限是『單筆』超過不跟；這裡是『整局總額』只提醒。
#    填『不限』或 0 = 不提醒。留空 = 用預設 30 萬。
單局總下注警告=30萬

# 【反試探】對手知道被自動跟單後，會用「乾淨大整數（5萬整數倍：50k/100k/150k/200k）
#    + 多格／齊頭同額」當餌，誘我們複製大額邊注放血。實測正常下注金額很「亂」
#    （90k、94k、20k、36k…），幾乎不會是 5萬整數倍，所以不會被誤判。
#    判為「試探局」就『該對象整局不跟（先不下、觀察）』；連續達門檻局數再升級反制。
#    反試探=開／關（預設開）。
反試探=開
# 【連續試探升級局數】同一對象連續這麼多局被判試探 → 執行下面的「試探升級動作」。
#    1=一出現就升級；2=連續兩局才升級；0=只「試探局不跟」不升級。預設 2。
連續試探升級局數=2
# 【試探升級動作】達門檻後要做什麼：
#    暫停 = 暫停整支程式並發 Telegram（對手多半已知道這帳號在跟單，停手最穩，人工換名後重啟）＝預設。
#    換桌 = 只停跟該對象並換桌（巡防）／停跟該對象（掛房），程式繼續跑。
試探升級動作=暫停

# 【影像比對門檻】（進階）影像比對「採用分數」：分數 ≥ 此值才算找到（0~1，越高越嚴）。
#    log 顯示「最佳分數=0.59 < 門檻」這種差一點比不中 → 調低；跟錯人 → 調高。留空=預設 0.55。
影像比對門檻=0.55

# 【影像比對領先差】（進階）最佳分數要領先第二名超過此差距才採用（避免長相相近跟錯人）。
#    分數很接近常比不中就調低、容易跟錯就調高。留空=預設 0.04。
影像比對領先差=0.04


# ===== ② 換房（巡防）模式專用 =====

# 【巡房房間】要循的房號，用逗號或頓號分隔。程式照順序在這些房間輪流巡（巡完一輪再從頭）。
#    開機時人在範圍外的房間（例如 No.5），會自動先換到範圍內的桌再開始巡。
#    留空 = 巡全部房號（不限制）。例：巡房房間=7、8、9、10、11、12
巡房房間=

# 【影像辨識房間】少數暱稱（藝術字/反白）OCR 讀不準，改用「比對長相」找。
#    指定這些名字固定待在哪一桌 → 只在那一桌用影像比對找它，其餘房間完全不找
#    （避免在別桌把長相相近的路人誤比中而跟錯人），也更快。
#    格式：暱稱:桌號，多個用「、」或逗號分隔。
#    留空 = 用內建預設（閃光福雷噓→No.15、三下治灸→No.14、還魂梅→No.16）。改房號就照下面這樣填：
影像辨識房間=閃光福雷噓:15、三下治灸:14、還魂梅:16
